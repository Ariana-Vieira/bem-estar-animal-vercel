# Slides da apresentação técnica

- `slides.html`: os 12 slides (formato 16:9). Abrindo o arquivo no navegador, é possível ver todos.
- `../APRESENTACAO-TECNICA.pdf`: o PDF gerado a partir dele.
- Roteiro de fala de cada slide: `../ROTEIRO-APRESENTACAO-TECNICA.md`.

## Como alterar um slide e gerar o PDF de novo

1. Editar o texto em `slides.html` (cada slide é um bloco `<section class="slide">`).
2. Abrir o arquivo no Chrome ou Edge, apertar **Ctrl+P**, escolher **Salvar como PDF**, deixar
   **Margens: Nenhuma** e marcar **Gráficos de plano de fundo**. Salvar como `APRESENTACAO-TECNICA.pdf`.

Os slides usam a internet para carregar a fonte (Outfit) e os ícones (Material Symbols).
